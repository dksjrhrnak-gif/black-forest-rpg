# P3 제작·세트·강화

## 기존과 구현 범위

기존 제작은 약초3→물약1 및 공용 대장간 이벤트의 제작 기록뿐이다. 장비 설계·실제 세트 효과·목적형 옵션 선택은 없었다. 명목상 세트 이름은 기존 장비에 존재했다. 실제 착용은 무기/방어구/장신구3슬롯이므로 2·3부위만 설계한다. p3-systems.js에서 기존 Game 메서드를 좁게 확장하며 engine.js/effects.js/1,000아이템 정의/P1·P2 데이터는 편집하지 않는다.

## 세트4테마

| 테마 | 2부위 | 3부위 |
|---|---|---|
| 토끼굴 | 최대 MP +2 | 적의 첫 행동 동안 회피 +3% |
| 산초의 귀환길 | 반사 피해 +1 | HP가 절반 이하일 때 흡혈 +2% |
| 노트르담의 종 | HP가 절반 이하일 때 방어 +1 | 회피 +2% |
| 하트 법정 | 치명타 +2% | 기절 확률 +2% |

효과는 canonical 기존 ID·정확한 슬롯·서로 다른 ID의 현재 장착 수로 매번 파생한다. 저장된 set 문자열 위조, 동일 아이템을 슬롯만 바꾼 중복은 인정하지 않는다. 교체/해제/복원 즉시 갱신되며 기본 옵션은 기존 계산 한 번, 세트는 별도 보너스 한 번만 적용한다. 최대HP를 읽을 때는 health 경로에 세트를 더하지 않아 재귀가 없다. 회피·치명타·흡혈·기절 기존 상한을 유지한다.

토끼굴3부위는 적의 turn=0인 첫 행동 동안만 동작한다. 충전/방어로 첫 행동을 보낸 뒤 다음 공격까지 이월되는 효과가 아니다. 반사/저HP 생존·기절 연계는 작은 기존 효과를 활용한다. 해당 테마가 아닌 장비의 set 이름은 그대로 보존하지만 세트 효과가 활성화된다고 표시하지 않는다.

## 강화와 조율

강화 최대+8, +1–5확정, +6/7/8은80/60/40%, 같은 단계2실패 후 다음확정. 이 규칙·저장된 plus/fails·능력치 증가(+당 무기공격2, 방어1, 행운1)는 유지한다. 파괴/단계 하락 없음.

- +1–3: 15×목표단계G, 광석2×목표단계(기존20/3).
- +4–5: 기존20×목표단계G, 광석3×목표단계.
- +6–8: 기존비용에 max(0,등급−1)×5×(현재plus−4)G, max(0,등급−2)광석 추가.
- 실패도 동일 비용을 쓰고 장비·강화는 유지한다. 성공·실패·자원 부족·최대단계를 한국어로 명시한다. 실제 견적을 제작/강화와 장비 비교 화면에서 공통 사용한다.

성공만 한 +0→8 금화/광석은 기본/고급690/102(기존720/108), 희귀720/102, 최상위810/111이다. 실패 확률은 동일하므로 고강화 기대 비용은 이 단순 합계보다 크며 특히 희귀 이상에서 높다. 첫 강화가 쉬워져도 제작/조율과 광석을 공유하므로 모든 슬롯 강화를 강제하지 않는다. 이미 강화된 장비나 보유골드를 소급 조정하지 않는다.

목적형 조율은 희귀 이상·옵션 있는 장착품의 마지막 옵션만 고른다. 금화220+등급×35+plus×15, 광석10+등급×2+plus. 기존 같은 아이템에 있는 옵션은 선택 불가. 옵션 값은 기존 min+floor(등급/2)로 낮게 고정한다. 앞선 옵션·등급·강화·실패 횟수는 유지하며 HP/MP를 새 최대치로 제한한다. 기존40G/광석4 무작위 재설정은 값의 상향 가능성과 낮은 비용을 가진 대안이다. 동일 옵션 재클릭은 거래하지 않는다.

## 검증과 한계

test-p3.cjs의15설계×수령3방법45거래, 각재료 부족·해금·잘못된 ID·취소·중복제작/수령·저장·분해순환, 96강화조건, 33조율결과와 중복, 4세트의0–3부위/저HP/첫행동/교체/복원을 검사한다. 실제 방어 행동에서 회피/반사가 발생하는 제어된 전투 probe도 있다. 이는 무작위 발동 빈도나 자연 해금에 관한 주장이 아니다.

동일 시드P3 전투17,664회(8직업,23착용구성,초/후반,시드3,HP2,일반/보스,전술2)의 모든 구성 승률 차0, 미활성 경로4,992개 저장/RNG 완전 일치. 세트 구성별 HP·턴·물약은 p3/combat-comparison.json. 일부 턴과 HP는 반사·회피·기절의 의도된 차이가 있고 최대 승률 변화10pp 안전장치를 통과한다. 모든114직업×모든장비×모든조건의 최적성을 보증하지 않는다. 제작은 15개 대표품만 적용하며 전설 설계/새 재료/대량 리밸런싱 없음.
