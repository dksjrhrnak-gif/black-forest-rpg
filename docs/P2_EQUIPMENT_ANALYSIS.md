# P2 장비·보상 선택성

전체1000개를 다시 설계하지 않았다. N–T의 기존 장비 감사와 P1 상태를 기준으로 고급 방어구/장신구 중 같은슬롯·등급·고정효과 조합의 반복과 하위품을 조사했다. 원본/현재 전수 비교는 p2/equipment-analysis.json. 고정등급 952개 중 벡터상 하위품 161개였다. 가변 등급·무작위 옵션·실제 플레이어 효용을 이 수치로 단정하지 않는다.

희귀도는 기본수치/옵션수/가격에 영향을 주지만1000독립 효과를 뜻하지 않는다. 공격/방어/HP 중심 기존 자동 장비선택은 MP/회피/흡혈 목적을 덜 평가한다. 판매/강화/희귀도·상한·슬롯·최소지역·1000ID는 유지했다.

994정의는 그대로다. 선정6종은 모두 기존고급1등급, 새 전설/아이템ID/전투효과는 없다. 수치는 기존 affix 범위 안이며 방어 또는 행운 기본수치는 모두 낮다. 획득한 기존 장비의 실제수치·강화·옵션은 세이브에 남은 값을 그대로 보존한다. 기존 장비를 강제 변환하지 않는다.

보상 변경: 종 추적 성공은 방어구, 도서관 낭독 성공은 장신구를 지정하되 기존 elite 확률·지역/천장 규칙을 적용한다. 떠돌이 상인은 기존 무작위55G상자를 유지하면서 무기/방어구/장신구55G상자를 함께 제공한다. 구매전 실제등급확률이 다른 상자처럼 오인하지 않도록 같은 정예확률임을 표시한다. 비용이 없는 최상위품 지급이나 모든 보상 인상은 하지 않는다. 물통 추적은 기존 정상 전투/드롭 보상이며 일반 재료·회복·기록 사이 대가가 다르다.

안전장치: 사건당1회, 즉시 기록, 동일사건 중복호출/로드 후 재지급0, 슬롯외 희귀도/가격/드롭률 변경0, 자원부족시 무료선택 유지. 단기전의 방어 손실과 장기전의 MP/흡혈 등 이득은 전후 전투로 따로 비교한다. 테스트 결과는 p2/equipment-comparison.json, 현재 자동/자연/브라우저 결과와 최종반영 상태는 P2_HANDOFF.md.

P3: 가치 기반 판매가격/경제재설계, 장비 제작, 세트 보너스, 강화시스템 확장, 엔딩별 장기결과. 이번에 구현하지 않았다.
