# 보스 인장 강제 전직

기준 main `d01469cd157dd76798673641e4128370a99e036d`. PR #8은 미병합이며 임의로 병합하지 않는다. 별도 `feature/forced-boss-career`에서 작업하며 이번 기능에 한해 테스트 통과 후 main/Pages까지 사용자가 승인했다.

## 정책

1/3/6지역 최초 보스의 frozen receipt를 실제 수령한 뒤 Tier1/2/3를 선택한다. 전투/보상 계산은 원본 그대로, UI는 보스 결과에서 전직 필요성을 알린다. 미수령 보상은 원래 장착/보관/판매로 먼저 받는다. 이후 camp의 선택 화면에서 미리보기 후 명시적으로 확정한다. 전직 완료 전 다음 지역과 전투·관계 여정으로 나갈 수 없다. 보상/미리보기/선택은 RNG를 소비하지 않는다. 기존 changeJob의 회복/계보 이력 처리를 재사용한다.

강제 전직의 기본 레벨/숙련 자격은 보스 인장이 대신한다. 추가 이야기/호감도/행동/비밀 조건은 유지하며 모든 일반 후보가 이 조건으로 잠긴 경우에만 기존 직접 자식 경로를 인장으로 열어 진행 막힘을 피한다. 실제 조건 값/스토리 플래그를 조작하지 않는다. 자발적 전직은 원래 조건을 적용한다. 기존 히든 직업 14종은 일반 강제 전직 대상에서 제외하며, 이미 발견하고 현재 조건을 만족한 히든은 강제 선택의 대안이 될 수 있다. 이미 목표 티어 이상이면 추가 전직하지 않는다. 낮은 티어의 과거 저장이 새 3/6지역 인장을 얻으면 직계 계보를 한 단계씩 선택해 따라잡는다.

## 저장과 UI

BF3 형식을 유지하며 `career.promotion`은 보상을 실제 수령한 경우에만 생성되는 작은 선택 대기 기록이다. 과거 완료 저장은 임의로 소급 잠그거나 초기화하지 않고 byte-identical 복원한다. 과거 미수령 보스 결과는 실제 수령 때 판정한다. 새로운 대기 기록은 지급된 지역 보스 영수증/계보/장면과 교차 검증한다. 전직 완료 시 기록을 제거한다. 재방문/회랑/중간 수문장은 강제 전직을 다시 만들지 않는다.

UI는 별도 ui-promotion.js/promotion.css와 read-only snapshot hook으로 구성한다. 기존 클릭 처리·FX를 재사용하며 자동 전직/진행 타이머가 없다. snapshot은 저장 권한이 없어도 현재 게임을 읽기만 하며 후보 미리보기로 상태를 수정하지 않는다. PR #8의 ui.js/style.css를 재작성하지 않아 후속 통합 변경 충돌을 줄인다.
