동일 브라우저·동일 CI 환경의 비교를 위해 QA용 dist 경로에 Git `1881f2b:index.html`을 추출한다. 수정 전후 모두 동일 기존 이미지·CSV를 사용한다. QA용 파일은 dist에만 생기며 저장소/공개 Pages에 새 화면으로 추가하지 않는다. 각 브라우저가 자기 baseline을 먼저 생성하므로 서로 다른 글꼴·브라우저의 절대 좌표를 섞어 비교하지 않는다.

4배 CPU 감속에서 30행동씩, 원래의 bounded FX 계측도 통과했다. 계측한 layer/token 최대3, 종료 후 애니메이션0, 90/90 저장/RNG 일치. 이번 단일 실험의 일반 FX 동기 클릭 중앙값 34.6ms / 95백분위 73.4ms는 다른 병렬 QA의 영향을 포함하며 FPS 또는 실제 저사양 기기 성능 개선으로 해석하지 않는다.

## 파일·남은 검토

실제 앱 변경은 `ui.js`, `style.css`, 생성한 `index.html`/`black-forest.html`이다. 후속 검수 `test-ui-review.cjs`, CI workflow, 기존 감사 결과 및 비교/인수인계/브라우저 증거 문서를 갱신했다. 기존 게임 테스트와 엔진/P1/P2/P3/자산/CSV는 그대로다.

남은 시각적 판단은 contain의 좌우 여백, 긴 서술에서 남는 스크롤, 축약한 전직 초상화와 장비 카드의 개인 취향이다. 실제 기기·장시간 플레이는 별도 검토가 필요하다. 기술적 병합 가능 여부는 최신 전체 CI 완료 후 판정하며, 모두 PASS여도 사용자 최종 승인 전 main 병합과 Pages 반영은 금지한다.
