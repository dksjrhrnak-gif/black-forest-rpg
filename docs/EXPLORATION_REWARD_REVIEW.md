# 탐험·이벤트·장비 성장 검토 — Phase Q/R

현재 코드 분석과 54회 자연 진행을 근거로 하며 아래 추가 이벤트·경제 변경은 **미적용 승인 제안**이다. 이벤트 원문/선택/비용/성공률/보상 전체18종은 gameplay/exploration.json에 보존했다.

## 실제 흐름과 반복

지역당12노드, 이야기 index0/4/8, NPC5, 쉼터3/7/11, 유리 늪·달의 도서관 index10 선택적 중간 수문장. 선택 버튼 하나가 다음 사건을 불러온다. 경로 갈림길 선택 시스템은 현재 없다. 이야기 선택은 기록/호감도/세력 평판을 바꾸지만 지역 노드 배열을 갈라놓지는 않는다.

200시드×8지역×12슬롯=19,200슬롯 조사에서 각 지역 이야기600·쉼터600이 고정이었다. 최근6이벤트 제외 규칙에 의해 연속 같은 이벤트는0회였다. 단, route fixture는 전체 여정의 secretPity 증가를 모두 모사하지 않아 확률은 조건부이며 자연 비밀방 등장률이 아니다. 이름이 다른 지역도 같은 기본 랜덤 가중치/공유18이벤트 pool을 사용해 지역 정체성의 기계적 차이는 제한적이다. 중간 수문장 지역2곳의 고정 슬롯은 실제 차이다.

보스 인장·쉼터·문학 대화는 진행 목표를 준다. 이야기를 매번 선택 index0으로 처리한 자연 정책만으로 분기 폭의 재미를 평가할 수 없다. 반복 피로·선택의 책임감은 플레이어 관찰이 필요하다.

## 장비·상점·제작·보상

자연 진행은 평균29–31개 획득/6–7개 교체, 장비 대부분은 판매 또는 가방에 남는 구조다. 첫 비교 정책이 공격·방어·HP·치명 중심이므로 흡혈/회피/행운 빌드의 실제 가치를 뜻하지 않는다. 1000명칭은 수집 폭을 주지만 독립 고유 효과1000개를 제공하지 않는다.

초중반은 기본 공격/방어 power와 옵션, 후반은 강화·옵션 조합이 성장한다. 강화는 최대+8, +5미만 확정·이후80/60/40%, 연속2실패 다음확정. 실패는 장비/수치 보존. 재련은40G+광석4로 마지막 옵션만 교체한다. 약초3 제작은 물약만 만든다. 장비 제작/세트 완성 보상/각 슬롯 전문 상점은 현재 없다.

판매가는 등급/강화에만 비례해 강력한 고정 옵션의 희귀성이 가격에 반영되지 않는다. 55G 랜덤 상자는 선택성을 주지 않는다. 개선 후보는 P2 슬롯을 고르는 상자 또는 구매 전 슬롯 확률 표시, P3 가치 기반 판매가/제작 확장. 확률·경제·신규 시스템은 승인 후 별도 PR에서 검증한다. 운/흡혈/치명 조합은 기존 상한 안에서 시험하고 모든 단일 옵션 증가를 무조건 ‘강화’로 표시하지 않아야 한다.

이번 안전 수정은 보상/장비 비교의 ATK/DEF/CRIT 등 내부 키를 ‘공격/방어/치명타’로 표시하고, 쇠 장검 w0에 검수한 전용2:3 이미지를 연결한 것이다. 계산·가격·드롭·강화·세트 시스템은 바꾸지 않았다. 비교 수치는 실제 compareGear를 그대로 사용한다.
