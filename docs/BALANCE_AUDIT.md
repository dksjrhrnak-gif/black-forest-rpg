## 성장·자원·제한

HP = 직업 HP + 8×(레벨−1) + 5×(캠프−1) + 생명 옵션 + 등불 평판≥3의 12. MP = 직업 MP + floor((레벨−1)/2) + 집중 옵션. 공격 = 직업 ATK + 2×(레벨−1) + 무기 power + 강화×2 + 맹공 옵션 + 저체력 효과. 방어 = 직업 DEF + floor((레벨−1)/2) + 방어구 power + 강화 + 수호 옵션 + 잉크 평판≥3의 2. 필요 XP = 22+13×레벨. 주력 스탯 이름은 설명 데이터이며 별도 투자 스탯 시스템은 없다.

공격은 MP 1을 회복한다. 방어는 피해 70% 감소와 MP 회복을 준다. 스킬 기본 소모 4에서 skillSaver를 뺀다. 치명타 최대65%, 회피35%, 흡혈45%, 행운20%. 모든 직업은 무기/방어구/장신구 3슬롯 사용 가능하며 검·활·지팡이별 착용 제한은 없다. 히든 발견과 현재 모험의 전직 가능성을 분리하고, 히든 진입 후 일반 경로를 닫는다. 구형 6슬롯은 이관 보존한다.

적 개별 이름은 지역별 공통 템플릿을 사용한다. 종족별 고유 스킬 데이터는 없다. HP 일반30+14a, 정예46+14a, 보스74+30a. ATK 일반8+3a, 정예10+3a, 보스12+3a. DEF a+(정예?2:0). 회차15%, 회랑 층당12%가 HP/ATK에 가산된다(a는 지역 index). 일반/정예 행동은 공격60·강공22·방어18 가중치, 보스는 4개 순환 패턴 중 지역a%4를 사용한다. 강공1.8배, 적 회복 최대HP10%. 동료 지원은 별도 적용된다.
