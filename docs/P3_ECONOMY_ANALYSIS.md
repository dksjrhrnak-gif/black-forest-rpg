# P3 경제 분석과 변경 근거

기준은 실제 main `b24007be4030f484c6867fb50f040fd55edd2edb`다. P1/P2 완료 문서 6개를 먼저 읽었다. `analyze-p3.cjs`가 골드 직접 변경 구문 35개, 공용 grant의 키별 지급, 이벤트21개 비용/성공·실패 보상, 의뢰11개, 신규15레시피를 기록한다. 상세는 p3/system-analysis.json이다. 이전 경제를 별도 VM의 실제 `git show` 소스로 실행하며 현재 구현으로 기준 결과를 만들어 내지 않는다.

## 발견과 선택

기존 가격 `10+등급×10+강화×5`는 기본성능과 옵션에 무관했다. 지역7·시드17의 슬롯 교차 구매/판매900회에서 최상위3개는 구매55G보다 높은60G였다. 전체 순손익은 −24,740G였으므로 기존 상자가 항상 확정 수익이었다고 주장하지 않는다. 품목별 수익 가능성을 제거한다.

새 식은 `min(50, 8+등급×6+min(8,floor(기본성능/3))+min(8,옵션평가합))+강화×2`다. 옵션별 평가는 기존 최소값으로 나눈 정수이며 각3까지, 합8까지다. 무강화 최대50G, +8 최대66G. 공격/방어/퍼센트 옵션을 무제한 단순 합산하지 않는다. 1,000장비×3지역×3강화의9,000가격에서 양의 정수/상한/성능·옵션 증가 시 비감소를 검사했다. 이는 실제 빌드 효용의 완벽한 감정가를 보증하지 않는다. 새 상자 구매/판매900회는 모두 최소5G 손실이며 강화·제작·조율 비용은 판매 차익보다 크다.

후반에는 재화가 남으므로 기존 보상을 일괄 줄이지 않고, 고정 옵션 제작/재활용과 낮은 수치의 목적형 조율을 선택 소비처로 넣었다. 희귀 장비는 제작으로 저렴하게 최고 성능을 얻을 수 없고 고급 세트의 약한 기본성능과 역할을 교환한다. 기존 무료 휴식과 넉넉한 회복을 유지하므로 난이도 전체 해결은 범위 밖이다.

## 남은 위험

후반 잔액은 여전히 평균1,681–2,690G다. 조율은 공격형에서 평균0.33회, 다른 정책에서는0이었다. 광석 경쟁과 이미 선호 옵션이 있는 장비, 제작 정책의 우선순위가 사용률에 영향을 준다. 사람이 선택할 의향·경제 압박·장기 회랑 자산 분포는 미검증이다. 강제 노가다나 보유골드 삭제로 이 문제를 가리지 않는다. 실제 플레이 관찰 후 조율 재료/정보 전달과 고강화·회랑의 골드 소비를 조정할 후속 후보로 남긴다.

추가 동일시드 거래 검증: 양쪽 지역7·시드17·동일900개슬롯교차상자에서 모든생성장비/최종RNG가일치했다. 기존순손익−24,740G, 변경후−28,767G, 변경후개별수익품목0. p3/resale-paired.json. 테스트지갑10만G는거래 경계검사용이며 위자연진행30G와 구분한다.

기존 재탐험·회랑의 전투수입과 공용사건 재등장 자체는 유지한다. 진행과 전투를 거친 반복 보상과, 거래/영수증/중복 호출로 비용 없이 재화를 복제하는 악용을 구분한다. 모든 재방문 수입을 제거했다고 보고하지 않는다. 극단적 반복 파밍의 시간당수익·장기재화분포는 후속 실측 대상이다.
