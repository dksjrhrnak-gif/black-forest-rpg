# P1 직업 개성 개선

사용자의 이번 지시는 이전 분석을 이어 PR #1과 P1을 중간 확인 없이 main/Pages까지 반영하도록 명시적으로 허용했다. 시작 main `5f87937`, PR #1 병합 `8a10eef63418b4d10fa75992ef1be4e554b31cc5`. P2/P3는 구현하지 않는다.

## 114직업 분석

[classification.json](p1/classification.json)에 모든 직업의 공격 방식·주력 명칭·생존·MP·상태이상·계보/숙련·장비 시너지·템포·위험·고유 효과를 기록했다. 기본 스탯/효과가 완전히 같은 직업은 없지만 25개 스킬 시그니처가 114직업에 공유됐다. 큰 공유 그룹은 근접 24 / 마법 16 / 조준 18 / 지원 18 / 계약 16이다. 패시브·티어·해금이 달라 동일 직업으로 간주하지 않는다.

기절/도트/흡혈/처형/콤보, 방어 후 공격 등은 기존 행동 개성의 근거다. 큰 공유 그룹은 차별화 여지가 있으며 이번에는 기존 효과 타입만으로 개선 가능한6종을 골랐다. 무기군 제한/직업 전용 자원은 구조 변경 후보로 보류했다. 구조 변경이 반드시 필요한 직업은 확정하지 않았다. 분류는 메커니즘 휴리스틱이며 사람의 재미 점수가 아니다. 주력 스탯 명칭은 테마 데이터이고 별도 투자 스탯 시스템은 없다.

## 전후 비교와 균형

변경6+대조6직업×3단계×6시드×2장비×2초기자원×3정책×2적종류×2HP=10,368쌍/20,736전. 독립VM에 고정된 이전 effects.js와 현재 구현을 각각 로드했다. 빈 초기MP는 공격/방어로 재생 가능하며 HP는 보상 수령 전에 기록했다. fixture는 해금 우회/동일레벨 비교로 자연 티어 획득 빈도가 아니다.

대조직업과 공격만 정책6,912개는 최종 저장/RNG까지 동일. 6스킬은 실제 피해/상태/적 행동/회복에 차이가 생겼다. 전체 평균 승률 변화는 약 −2.1~+5.9%p, 직접 피해를 올리지 않고 회복/제어와 교환했다. 집계 회귀 안전창은 승률 ±10%p / 평균 템포 ±25%이다. 이는 개별 상황의 완전한 균형을 보증하지 않는다. 약장비 조건의 역행술사 중반 스킬 승률 증가는 20.8%p로 더 크며 실제 자연 경로의 Tier3 획득과는 구분한다.

## 저장·진행·모바일

이전 엔진에서 만든 114직업 × 캠프/스킬 사용 후 전투 = 228저장을 완전 일치 복원했다. 새 도트/약화 저장도 검사했다. 기존 BF1/BF2/BF3·옛 6슬롯 회귀를 유지했고 저장 버전/구조/마이그레이션 추가는 없다. 자연 54/54엔딩·저장 474일치·실패 0. 공격 정책 1부활, 스킬/전술 0부활. 실제 독서 시간/재미 측정으로 환산하지 않는다.

Chromium/WebKit 각각 360/390/430에서 18개 실제 ‘이전 저장 로드→새 스킬→상태 저장→새로고침’ 검사를 통과했다. 스킬 결과가 엔진과 일치하고 긴 설명/조작부 넘침, 콘솔/런타임 오류는 0이다. 같은 3폭의 일반 여정/장비/보상/히든/엔딩/이미지 회귀도 두 엔진에서 통과했다.

## 필요한 배포 보완

PR #1은 Pages 배포와 공개 CI 검사가 경쟁해 최초 공개 WebKit job이 실패했다. 배포 후 공개 HTML/149자산/30시각 화면/3폭 여정은 통과했고 실패 job 재실행도 성공했다. wait-pages-deployment.cjs가 해당 SHA의 배포 성공 후 검사하도록 보완했다. root CSV 다운로드가 옛 스킬명으로 남지 않도록 export-site.py가 정식 data/CSV 3개를 root와 dist에 같이 복사하고 HTTP 바이트를 검증한다. 모두 이번 P1 공개 검증에 필요한 최소 수정이다.
