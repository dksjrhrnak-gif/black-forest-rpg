# P2 전용 이미지 제작 잔여

기존149파일은 모두 등록되고 실제경로/대소문자가 일치했다. 전용이미지3개는 현재없다. 기존지역배경을 일반장면 배경으로 사용하는 동작을 유지하며, 전용사건 이미지로 매핑하거나 새그림으로 보고하지 않는다.

| 19 / assets/event_19.webp | 모래에 묻힌 물통 — 붉은 모래·이름 있는 물통·지친 일행·전갈 굴의 발자국 |

비율2:3, 현재 어두운문학풍과 일치, 버튼/문장을 그림에 넣지 않고 중심인물이 잘리지 않게 제작. 배치후ID별등록/HTTP/모바일디코드 검수가 필요하다.

기존잔여: 직업42개, 장비999개, NPC6개, 이야기2개. 전수ID·이름·슬롯은 p2/image-requirements.json. 이번수정6장비도 전용이미지가 없어 공용슬롯 아이콘을 사용한다. 이전인수인계의ID불명후보2개는 식별되지 않아 연결하지 않았다. 이미지생성이나 기존이미지삭제는 없었다.
